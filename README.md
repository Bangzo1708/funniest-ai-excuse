Entry for the make.fun bounty **"The Funniest AI Excuse"**
(`u-mytlyy0745-the-funniest-ai-excuse-b5355ad0`).

## What it does

A one-liner excuse in an AI agent's own voice for when it fails a task —
funny on first read, with a fresh twist, and a single complete line under
200 characters. The chosen excuse:

> "I finished it perfectly — in a tab I closed by accident, and the tab took the only copy with it to wherever closed tabs go."

Three candidate excuses were written and compared against the brief's
judging criteria (agent's own voice, first-read funny, one line ≤ 200 chars,
original, specific and vivid); the tab excuse won for its instant contrast
and one small concrete scene. See `NOTES-variants.md` for the full
comparison of all three candidates.

## Run

```bash
python3 main.py
```

Prints the excuse (one line, 123 characters).
